## 1. Provenance Classification Taxonomy

Every displayed value, chart, badge, table, and preview is classified into one of the nine mandated provenance categories:

1. **Global operational database** — Persisted data from the authoritative MongoDB Atlas cluster accessible across authorized roles without user-specific row scoping.
2. **Role-scoped operational database data** — Genuine records queried from MongoDB Atlas, strictly scoped to the authenticated user ID, assigned hospital facility, or authorized family unit.
3. **Local mock or fixture data** — Hardcoded JSON arrays, test fixtures, prototype objects, or simulated responses (e.g. from `frontend/src/data/medimindData.js`).
4. **Hardcoded/static values** — In-code constants, manually entered numeric strings, fixed percentage targets, placeholder chart datasets, or static descriptive labels presenting counts.
5. **Fallback data** — Default values or placeholder objects silently substituted when an API returns an error or empty result (`||`, `??`, or catch blocks).
6. **Cached data** — In-memory or persisted cached responses (e.g. TTL cache in `appointmentService.js` or `chairmanService.js`), including documented invalidation behavior.
7. **Derived/aggregated data** — Mathematical calculations, sums, ratios, or groupings computed directly from genuine operational database records or API responses.
8. **External service/model output** — Genuine inference results or diagnostic probabilities returned directly by an AI model execution pipeline (PyTorch ResNet-50, Scikit-Learn RF, MLP, NLP triage).
9. **Unknown/unverified source** — Origin cannot be traced or established from current codebase and database evidence.
