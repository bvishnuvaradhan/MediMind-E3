# Diabetes Risk Model Card

## Model Overview

| Property        | Value                                           |
|-----------------|------------------------------------------------|
| Model name      | `diabetes_risk`                                |
| Model version   | `0.1.0`                                        |
| Model type      | Random Forest classifier (scikit-learn)        |
| Input type      | Structured health parameters (HEALTH_PARAMETERS) |
| Output          | Risk probability (0–1), risk category (HIGH/LOW) |
| Threshold       | Selected from validation data only             |
| Dataset         | Pima Indians Diabetes Database (768 records)   |

## Intended Use

This model is a **clinical decision-support tool**. It estimates diabetes risk
from structured health parameters to assist a qualified healthcare professional.

It is **not** a diagnostic tool. Results must not replace clinical examination,
laboratory testing, or professional medical judgment.

## Output Interpretation

- `risk_score`: Estimated probability of diabetes (0.0–1.0).
- `risk_level`: `HIGH` if `risk_score >= threshold`, `LOW` otherwise.
- `confidence`: Set to `risk_score` for this version. Not independently
  calibrated; treat with appropriate caution.
- `disclaimer`: Mandatory non-diagnostic disclaimer included in every response.

## Limitations

1. **Population scope**: Trained exclusively on Pima Indian women aged ≥ 21.
   Generalization to other populations is not validated.
2. **Class imbalance**: The training data is approximately 65% negative /
   35% positive. Precision at the chosen threshold will reflect this imbalance.
3. **Feature quality**: Glucose, BloodPressure, SkinThickness, Insulin, and BMI
   contain biological zeros in the source data, treated as missing and imputed
   with training-set medians. Imputed values reduce effective data quality.
4. **Threshold provenance**: The operating threshold is selected from the
   validation partition only. Test results are not used for threshold selection.
5. **Calibration**: Probability calibration has not been independently verified.
   The Brier score is reported as a calibration indicator.
6. **External validation**: This model has not been externally validated on any
   clinical population. External validation and clinical governance are required
   before any deployment in a clinical setting.
7. **Not a diagnosis**: Under no circumstances should model output be presented
   as a medical diagnosis or a substitute for professional clinical assessment.

## Subgroup Behaviour

Subgroup performance (by age band and other available features) is reported in
`training_report.json`. These results are validation findings only. They do not
constitute evidence of clinical fairness or safety for the groups shown.

## Model Versioning

Every stored prediction carries `model_name` and `model_version`. If the model
is retrained or updated, the version must be incremented. Historical prediction
records must never be overwritten to appear as if generated by a newer model.

## Mandatory Disclaimer

Every API response includes the following non-negotiable disclaimer:

> "This is an AI-assisted diabetes risk estimate, not a medical diagnosis.
>  Consult a qualified healthcare professional."
